# Laboratório de Classes Protheus

[English](README.md) &nbsp;|&nbsp; **Português (Brasil)**

Exemplos de Programação Orientada a Objetos (POO) em ADVPL no TOTVS Protheus — classes, herança, métodos e design patterns.

> **Aviso Legal**: Exemplos educacionais. Todos os nomes de classes e estruturas de dados são fictícios.

## Exemplos

### Classe Base
Classe abstrata com construtor, métodos e encapsulamento de propriedades.
  

### Padrão Repository
Camada de acesso a dados usando o padrão repository para tabelas do Protheus.
  

### Classe de Serviço
Camada de regras de negócio com padrão de injeção de dependências.
